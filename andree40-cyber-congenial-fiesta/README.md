# Antes del clic

Guía educativa, adaptable a celulares y hecha como una página estática. No requiere instalar aplicaciones ni cargar dependencias externas.

## Publicación

Publica `index.html` en cualquier alojamiento web estático con HTTPS. Después de publicar, comparte la URL por WhatsApp o el aula virtual; el botón **Compartir** usa la función nativa del dispositivo cuando está disponible y, en caso contrario, copia el enlace.

Para distribuir un código QR, genera uno con la URL pública final de la página después de alojarla.

## Contenido

La página incluye cinco ejemplos representativos redactados para esta guía, una lista de verificación interactiva, pasos de respuesta y denuncia, y una autoevaluación que se procesa localmente en el navegador.
