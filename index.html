Los mensajes cambian, pero las señales se repiten: urgencia, premios inesperados y pedidos de claves o códigos.

✉️01 / 05

Phishing

Un correo o mensaje falso imita a una empresa para robar tus claves.

“Tu cuenta será suspendida hoy. Confirma tus datos aquí: [enlace sospechoso]”Ejemplo representativo, redactado para esta guía.

Señales de alerta

  • Remitente o dominio extraño.
  • Urgencia y enlace inesperado.

Qué hacer: no abras el enlace; entra a la web oficial escribiendo la dirección tú mismo.

💬02 / 05

Robo de WhatsApp

Te engañan para que entregues el código de registro y toman tu cuenta.

“Te mandé un código por error, ¿me lo reenvías? Es urgente.”Ejemplo representativo, redactado para esta guía.

Señales de alerta

  • Te piden un código de seis dígitos.
  • El pedido llega incluso desde alguien conocido.

Qué hacer: nunca compartas códigos; activa la verificación en dos pasos.

📞03 / 05

Vishing

Una llamada intenta asustarte para que reveles datos o autorices algo.

“Somos del banco. Hay una compra sospechosa; dicta el código que te acaba de llegar.”Ejemplo representativo, redactado para esta guía.

Señales de alerta

  • Presión para actuar sin colgar.
  • Te piden claves, códigos o instalar una app.

Qué hacer: cuelga y llama al número oficial de tu tarjeta o banco.

🛍️04 / 05

Páginas falsas

Una tienda o portal copiado busca cobrarte o capturar tus datos.

“¡Oferta solo por hoy! Transfiere ahora para separar tu producto.”Ejemplo representativo, redactado para esta guía.

Señales de alerta

  • Precio demasiado bueno y apuro por pagar.
  • Sin datos verificables ni medios de pago seguros.

Qué hacer: busca la tienda por separado, revisa su dirección y evita transferencias a desconocidos.

📲05 / 05

Apps falsas

Una aplicación imita un servicio conocido y puede robar información o controlar el equipo.

“Actualiza tu envío: descarga esta app de seguimiento fuera de la tienda oficial.”Ejemplo representativo, redactado para esta guía.

Señales de alerta

  • Archivo APK o descarga desde un enlace.
  • Permisos que no tienen relación con la app.

Qué hacer: descarga desde la tienda oficial y comprueba quién la publica.

Si ya caíste,
todavía puedes actuar.

No borres las pruebas ni respondas al estafador. Pide ayuda a alguien de confianza y sigue estos pasos.

  1. Protege tu dinero

    Llama al banco desde su número oficial para bloquear tarjetas, cuentas o transferencias que corresponda.

  2. Recupera tus cuentas

    Cambia las contraseñas desde un dispositivo seguro; cierra sesiones desconocidas y avisa a tus contactos si tomaron tu cuenta.

  3. Guarda las pruebas

    Conserva capturas, números, enlaces, comprobantes y fechas. No reenvíes el enlace sospechoso.

  4. Denuncia

    Acude a una comisaría o consulta con la Dirección de Investigación de Ciberdelincuencia de la PNP para recibir orientación sobre la denuncia.
